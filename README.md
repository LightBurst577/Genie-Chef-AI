# Genie Chef AI 🧞‍♂️🍳

Genie Chef AI is a smart, interactive web application that helps users discover recipes based on the ingredients they have at home. Simply input your available ingredients, and let the AI genie conjure up the perfect culinary creation.


## 🚀 Features

- **Dynamic Ingredient:** Easily add and manage a list of ingredients in real-time.
- **AI-Powered Recipe Generation:** Leverages the AI to suggest recipes based on your specific ingredient list.
- **Modern UI/UX:** Built with a clean, intuitive interface featuring responsive CSS styling.

## 📖 How to Use

1. Type your available ingredient into the input box (e.g., "oregano").
2. Click the **+ Add Ingredient** button.
3. Repeat the process until all your ingredients are listed.
4. Submit the list to let **Genie Chef AI** generate a customized recipe blueprint for you.

## ⚠️ Important Note: Genie Limitations

Even magic genies need a break! Please keep in mind that **this genies can get tired**.

- **Rate Limits:** If you request too many recipes in a short period, the AI might temporarily stop responding to catch its breath.
- **Cost Constraints:** This have strict usage caps, meaning the genie might "go to sleep" if daily limits are exceeded.
- **Patience is a Virtue:** If the app stops generating recipes, wait a few minutes/hours/days before trying to summon the chef again.
